# 校园账学簿

## 1. 需求分析

### 1.1 目标

面向校园用户提供轻量、离线可用的收支管理与学习习惯管理工具。用户可从自己的视角录入数据，完成查询、编辑、删除、统计、图表查看以及数据迁移的闭环；同一设备可在学生、同学、辅导员等多角色视角之间切换。

### 1.2 功能需求对应

| 需求 | 实现 |
| --- | --- |
| 消费/收入、分类管理、月度汇总 | 收支页、收支表单、分类管理页；按月计算收入、消费、结余 |
| 饼图/柱状图 | `utils/charts.js` 原生 Canvas 绘制消费分类饼图、消费趋势及学习趋势柱状图 |
| 学习时长/科目/连续打卡 | 学习页和打卡表单；基于连续日期集合计算 streak |
| 进度可视化 | 首页和学习页科目目标进度条；统计页科目分布 |
| 增删改查 | 两类记录均支持新增、列表查询、编辑与删除；分类支持新建、编辑、受引用保护的删除 |
| 多角色/多用户 | 我的页可创建、切换角色；业务查询始终按 `currentUserId` 过滤 |
| Excel/CSV/JSON | 数据中心可导出 JSON、CSV、SpreadsheetML `.xls`；可解析并按合并/覆盖导入 |
| 持久化 | `wx.setStorageSync` / `wx.getStorageSync` 本地同步存储 |

## 3. 数据结构

根状态存储在键 `campus_ledger_study_v1`：

```js
{
  version: 1,
  currentUserId: 'u_student',
  users: [{ id, name, role, avatar, color }],
  categories: [{ id, scope, type?, name, icon, color, targetMinutes? }],
  financeRecords: [{ id, userId, type, amount, categoryId, date, note }],
  studyRecords: [{ id, userId, subjectId, minutes, date, note, mood }]
}
```

字段约束：`scope` 为 `finance` 或 `study`；收支 `type` 为 `income` 或 `expense`；日期统一存为 `YYYY-MM-DD`，便于按月前缀查询；金额和时长均为正数。分类在有引用记录时不可删除，避免孤儿记录。

## 4. 核心逻辑说明

### 4.1 持久化与 CRUD

应用启动时 `store.initialize()` 检测本地状态。若为空则写入演示数据；否则做结构归一化，避免旧版或不完整导入导致页面报错。记录新增时自动分配包含前缀、时间戳和随机段的 ID，并绑定当前用户；更新与删除按 ID 精确操作。

### 4.2 统计

- 月度收支：筛选 `date` 以目标 `YYYY-MM` 开头的记录，再分别累加收入和消费。
- 分类统计：以 `categoryId` 或 `subjectId` 分组，聚合金额/分钟，返回颜色与名称供视图、饼图共用。
- 连续打卡：将打卡日期去重为 Set，从今天反向逐日检查，首个缺失日停止；这样同一天多次学习也只计作一天。
- 目标进度：月内科目时长 ÷ `targetMinutes`，显示值限制在 100%。

### 4.3 图表

为保持零依赖，图表用 `wx.createCanvasContext` 绘制。统计页启动时读取窗口宽度，按卡片可用宽度设置 Canvas 的实际 `width/height` 属性和内联尺寸，绘图坐标也同步缩放，避免默认 300×150 画布造成拉伸、裁切或高度异常。饼图根据全部分类数值累积角度，中心显示总支出；下方构成明细展示每个分类的金额和占比。柱图以当前数据最大值作归一化比例绘制，并标注月份/日期、实际值和单位。空数据会显示“暂无数据”，不会出现除零错误。

首次初始化的学生视角包含六个月的消费趋势演示数据（每月两笔、覆盖餐饮/交通/学习用品/生活日用），可直接验证柱状图；如设备已有旧本地数据，可在“我的 → 数据导入、导出与备份 → 恢复演示数据”重新载入。

### 4.4 导入导出

JSON 保留完整状态，最适合完整恢复。CSV 使用 UTF-8 BOM，降低 Excel 打开中文乱码风险。Excel 导出为 SpreadsheetML `.xls`，可被 Microsoft Excel/WPS 直接打开。CSV 与 `.xls` 导入均采用导出表头格式；找不到分类时自动创建相应分类。导入后用户选择：

- 合并：以 ID 去重，将新数据追加到当前状态；
- 覆盖：用导入的完整状态替换本地状态。

## 5. 环境配置与运行

| 项目 | 要求 |
| --- | --- |
| IDE | 微信开发者工具稳定版 |
| 小程序基础库 | 3.4.9+ |
| AppID | `touristappid`（可替换为自己的 AppID） |
| 依赖 | 无 npm 依赖、无服务端依赖 |

导入项目根目录后直接点击编译。文件导入/导出使用微信小程序文件系统和 `chooseMessageFile`，在真机或开发者工具中按平台能力选择文件即可。

## 7. 调试建议

在微信开发者工具中开启“不校验合法域名”，使用“清除缓存 → 清除数据缓存”可重新验证首次初始化。调试文件传输时用真机或开发者工具的文件选择能力；若导入失败，数据中心会展示格式提示，优先使用本应用导出的模板文件。
